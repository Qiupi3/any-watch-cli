# any-watch-anime

Stream anime sub Indo from your terminal: **HiAnime, AnoBoy, Oploverz, OtakuDesu, and Samehadaku**.

```bash
any-watch-anime "Solo Leveling"
any-watch-anime "Frieren" -e 1-5
any-watch-anime "One Piece" -q 1080p

# Pick a site
any-watch-anime "Frieren" --site anoboy
any-watch-anime "One Piece" --site oploverz -e 1180
any-watch-anime "One Piece" --site samehadaku

# Interactive site picker
any-watch-anime

# List every anime site and mirror
any-watch-anime --list-sites
```

Anime providers supply hardsubs; Oploverz and OtakuDesu/Samehadaku mirrors may also expose softsub tracks.
