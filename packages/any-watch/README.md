# any-watch

Universal terminal streaming suite — search movies, TV, anime, and Asian drama.

```bash
any-watch "Solo Leveling"
any-watch flix "Inception"
any-watch anime "Frieren"
any-watch drama "Crash Landing on You"

# Interactive category → site picker
any-watch
any-watch --pick "Solo Leveling"

# Use one category or one site
any-watch --provider anime "Frieren"
any-watch --site kisskh "Squid Game"

# Show every category, site, and mirror
any-watch --list-sites
```

See the root README for the full provider catalog, versioning/update scheme, and configuration.
